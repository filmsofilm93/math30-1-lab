# Math 30-1 Lab

An exam-aligned study app for Alberta Mathematics 30-1. It runs entirely in the browser (PWA, offline, no accounts).

- `docs/architecture.md`: stack and design decisions
- `docs/skill-graph.md`: the skill graph outline
- `src/content/curriculum.json`: outcomes, skill nodes, misconceptions (generated by `docs/build_curriculum.py`)

## Develop

```
npm install
npm run dev      # local server
npm test         # checker + generator property tests (SEEDS=500 npm test for a deeper run)
npm run build    # typecheck + production build
```
